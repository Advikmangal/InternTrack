# InternTrack logo

Generated with the built-in image generation tool. The transparent PNG is used in the workspace header, sign-in page, and favicon. The sign-in page displays a white version using a CSS filter. Adjacent live text supplies the accessible brand name.

## Generation prompt

Use case: logo-brand. Asset type: InternTrack web app brand symbol and favicon. Generate one distinctive, professional flat logo symbol: an interlocking lowercase i and t monogram with a subtle ascending step cut into its silhouette, evoking a personal opportunity register and career progress. Strong editorial serif-inspired geometry, confident thick strokes and open negative spaces so readable at 40px. Single solid charcoal #282820 ink, genuinely transparent background. Center the mark in a square composition, filling about 85% of the canvas. No wordmark, no surrounding frame, no mockup, no gradients, no shadows, no texture, no additional text. Fits a warm paper and vermilion editorial identity.
